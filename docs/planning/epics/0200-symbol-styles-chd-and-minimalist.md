# 0200: Symbol styles: CHD and minimalist

## Status
In Progress, paused 2026-11-20 until the survey answers are in. Logged 2026-11-19. Follows the implementation of [0194](0194-improve-on-the-bpmn-notation.md), whose symbols become the "CHD" style. The comparison page and its survey are built and live; nothing in the app changes until the answers say whether a second style is worth its standing cost.

## Goal
Let a person draw and read the Behaviour kinds in one of two styles, **CHD** (the symbols of 0194) and **minimalist** (plain, familiar flowchart-like shapes and marks), chosen to suit themselves and the audience, and compare how people fare with each, as a small user study.

## Decided
- **A preference, not part of the file.** The two styles draw the same kinds from the same file; only the look changes, like the theme or the font. The setting is in Preferences (per person and machine), seeded with a default like every preference.
- **Symbols only, not colours.** The frames and marks differ; both use the same one-shade-per-family colours, so the study compares symbols, and "the icons mean the same" stays true.
- **Export and the command line can choose.** The SVG, PNG and draw.io exports take a symbols option that defaults to the preference, so a deck for one audience is made without changing the setting; the CLI export takes `--symbols chd|minimalist` and defaults to CHD (it has no preferences to read), so a CI pipeline can say which it wants.
- **The names are "CHD" and "minimalist"**; neither refers to another notation.

## Tasks
- [ ] **A mockup set to compare,** like `docs/experiments/behaviour-alternatives.html`: a sheet with the basic shapes of every kind, **CHD on top and minimalist below**, in the same sizes and themes, then **two dark-theme example flows**, one drawn entirely in each style. The minimalist set is designed here: frames (a diamond for a choice fits the square frame, its vertices land on the side midpoints), marks and rings, including how it draws the human action. The sheet is the stimulus for the study and the basis for the rest.
- [x] **A first comparison, for showing people:** [docs/experiments/symbol-styles-comparison.html](../../experiments/symbol-styles-comparison.html), one home healthcare process drawn three ways from one layout, labelled **A = BPMN 2.0, B = minimalist, C = CHD** in the file's own order (the page does not name them; the key is only here). On the page the letters are shuffled for every visitor, `#order=bpmn,min,chd` in the address fixes the order, and the survey stores the ratings by style with the order the visitor saw. Light and dark, stacked, side by side or one at a time. **The minimalist style is the symbol set the app had before 0194** (the 13 kinds of ADR 0180, in git at `72c90f1~1`): a decision with a cross, an inclusive choice with a ring, a parallel choice with a plus, a start as a plain circle (the play triangle came with 0194), an end as the heavy ring without a tick, the person, gear, sub-flow and loop marks on the steps. Drawn here in today's one-shade-per-family colours so only the symbols differ (the old set also had a green start, a red end and a blue parallel choice). Second round: colour vision toggles (protanopia, deuteranopia, tritanopia, greyscale), taller lanes, notes meeting their dashed line in the middle of the text, the person mark in the bottom right corner, and more kinds: a parallel split and join, an automatic step, a sub-flow, a failed end and an end that aborts the whole flow. B and C now differ in the decision, parallel and sub-flow marks, the automatic step, the start and the ends. The old set has no outcomes, so in B all four ends look the same and only their labels tell them apart; in A they are an error end (lightning) and a terminate end (solid disc). In C the end that stops the whole flow is drawn here as the same heavy ring around a darker centre with a light stop square (the app draws it as a solid disc with the mark cut out, ADR 0193).

## Notes
- **Picking it up after the study.** The tasks from the ADR down wait for the answers; they build a second style, which every later kind has to be drawn in too. The answers are in the sheet's `Svar` tab, one row per person, round `symbols-3`. Ratings are stored by style (`bpmn`, `min`, `chd`); `rekkefolge` says which style was A, B and C for that person, which is also how to read a comment that says "A". Compare the three styles on welcoming (the first impression, asked before the person studied the drawings) and on ease of reading, and split by `kjent_nivaa` (BPMN familiarity) and `tema`. Rows with round `test` are setup tests. The page is `docs/experiments/symbol-styles-comparison.html`, built by `build-symbol-styles-comparison.mjs` next to it; the copy in the repo has no endpoint, and the hosted copy was built with `SURVEY_ENDPOINT` set (the address is the maintainer's, not kept here). A changed page needs a new round id (`SURVEY_ROUND` in the script) so old and new answers stay apart.
- A new kind needs a look in both styles from then on; that is the standing cost, accepted for the study and the audiences.
- Kind ids and the file format do not change; an older app ignores the setting.
- The cross of a failed end in the CHD style can be taken for the minimalist decision (an X in a diamond). Look at the two side by side in the comparison sheet, and in the study ask whether it is mixed up; the minimalist style may need a different mark for a failed end.
