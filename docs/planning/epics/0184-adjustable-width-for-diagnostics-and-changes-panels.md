# 0184: Adjustable width for the diagnostics and changes panels

## Status
Not Started. Logged 2026-11-07; a small fix.

## Goal
The diagnostics panel and the changes (review) panel have a fixed width. Let a person drag their edge to make them narrower, so more of the canvas shows, or wider, to read long messages.

## Tasks
- [ ] A drag handle on the panels' inner edge; the width is kept in the preferences and applied on the next start
- [ ] A minimum and a maximum width, and a double-click that restores the default
- [ ] Check the other side panels for the same need, and share the handle if they have it
- [ ] Look at it in the app, in both themes, with the window narrow
