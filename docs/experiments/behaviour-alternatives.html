The 13 kinds as the app draws them now, at the sizes a new one gets (steps 150 × 56, choices 48, events 40). The dashed outline marks the current design wherever it appears below.

2. Alternatives, kind by kind

Each row starts with today's drawing, then ideas borrowed from other places: media players, forms, logic diagrams, UML, signs and everyday icons. Marks are stroked in a 24-unit box, the way the app draws its own. A few change the colour or the outline as well as the mark, and say so.

3. Your picks so far

The step shape stays. Stacked layers for the sub-flow, the robot for the automatic step, the play triangle for start and the tick for end are in. The plain circle stays the event; the signal is shown as a trial. The kinds not yet discussed (timer, message, repeat) are as today (dashed outline). The three choices are set A of round two: a sideways fork, two overlapping rings, two bars.

4. Choices, round two

The aim: marks as simple as the originals, with a meaning, and not turned copies of each other (a plus and a cross are the same lines at a different angle). Each set is decision, inclusive choice and parallel, at full size and, to the right of it, at half size, which is how they look zoomed out. Judge the half-size ones first.

5. Choices, round three: one symbol, a count

A fork, a diamond or a square says "this branches"; a count says how many of the paths are taken. 1 is exactly one (a decision), 1+ or 1–n is one or more (inclusive), n or all is every one (parallel). The count is the only thing that differs, so there is no turned copy to mix up. Same layout as before: full size, then half size.

6. Colours, on the picks so far

The marks now say what a kind is, so colour has less to do. Each block below shows the whole set as picked (set A for the choices) under one palette. What to judge: are the three families apart at a glance and in greyscale; is a user step told from an automatic one by its icon alone; are start and end apart by their marks and rings, with no red against green. The maintainer's rules for this round: each family has one lightness, evenly spaced from the others, so the families differ without colour; shape and icon are the main differentiator; and the end is not red, since red reads as an error. Switch Vision to Greyscale, and Size to 50%, before deciding. Diamonds are not on this sheet: set A keeps the square frames.

7. Events: starting a flow, and inside one

A toggle on the three events that can be either (event, timer, message): starts a flow draws one ring, in the flow two. The generic start (play triangle) and the end (tick, heavy ring) have no toggle. The palette is set 2 of section 6. Each pair is "starts a flow" then "in the flow".
