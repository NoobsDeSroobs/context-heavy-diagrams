# Task: fix the edge problems in a diagram

The folder holds a diagram, `small.chd` or `large.chd` (you are told which). The tools report layout problems in it: edges drawn across elements they do not join, edges that cross each other, and edge labels sitting on things.

Make the diagram read better by fixing those problems. Keep every element, every connection and every label as it is: do not add or remove any, and do not change what an edge joins. You may move and resize elements, change which connection point an edge uses, add connection points, bend an edge through points, and change an edge's routing style.

When you are done, give a short account: how many problems there were at the start and how many are left, what you did, and for every problem you left, why.

Work in the file where it is: it is already there, so edit it with `edit_diagram` (the person has allowed changes to existing files).
