A real design conversation happened first (see [ADR 0050](docs/decisions/0050-freeform-line-as-node-type.md)): the line is a new `DiagramNode` type (`'line'`), not a new top-level file entity or a unification with edges — that unification (a connector whose ends are either bound to a node or free in space, which would also retire `AnchorNode`'s dangling-edge-end placeholder) was identified as the real eventual shape but deliberately deferred so the new curve mechanism didn't put currently-working edge code at risk; [epic 0032](docs/planning/epics/0032-edge-routing-and-waypoints.md) is now expected to reuse this epic's geometry directly rather than solving routing from scratch.
