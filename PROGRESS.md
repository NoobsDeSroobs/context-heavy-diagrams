# Progress

Short pointer only — the full backlog lives in [docs/planning/](docs/planning/), decisions in [docs/decisions/](docs/decisions/).

## Status: MVP complete (2026-08-20)

Every core requirement from [docs/project-brief.md](docs/project-brief.md) is implemented, merged to `master`, and confirmed working by the user. The last outstanding one — dark/light mode (brief item 7) — landed as [epic 0005](docs/planning/epics/0005-dark-light-mode.md); see [ADR 0027](docs/decisions/0027-theme-default-follows-system.md) for why the default follows OS preference rather than being hardcoded, which was a specific concern raised before building it. Export (brief item 10) is explicitly "nice-to-have" in the brief itself, correctly still outstanding as [epics 0010/0016](docs/planning/epics/0010-export.md).

Substantial work beyond the brief's core list has also landed, driven by real usage rather than the original scope: containers, a full styling panel, undo/redo, alignment/snapping, configurable connection points, drag-edge-to-create-shape, edge reconnection, a multi-window diagram model (one `BrowserWindow` per diagram, not tabs), a unified tag/metadata system with diagram-level required-tags templates (including propagating a template down a link tree), and tag-based highlight overlays with group/bulk toggling. Full detail lives in each epic's own doc under [docs/planning/epics/](docs/planning/epics/); design reasoning for anything with real debated alternatives is in [docs/decisions/](docs/decisions/) — see [docs/architecture/overview.md](docs/architecture/overview.md) for a current component-level map of what's actually built.
