# Organisation

- **`motivation-goals.chd`**: modernization drivers and goals. Four drivers (declining ridership, legacy system risk, regulatory pressure, rising customer expectations) lead to three goals (modernize the platform, improve compliance, grow ridership), which are measured by three objectives; the edges are labelled "motivates" and "measured by". All ten elements have substantial notes behind them, real reasoning rather than one-line labels.
