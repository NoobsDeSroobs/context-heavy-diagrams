# Examples

Real, working `diagram.json` files, kept as manual regression fixtures and as a starting point for anyone trying the tool out. Each subfolder is one self-contained diagram, following the same folder-per-diagram format described in [docs/project-brief.md](../docs/project-brief.md) (`diagram.json`, plus `assets/`/`details/` once those features exist).

- **`hello-world/`** — the minimal case: two nodes, one edge. Proves save/load round-trips correctly.

More get added as features land — e.g. a containers example once epic 0004 exists, a styled/iconed one once epics 0003/0007 exist — so this folder ends up demonstrating whatever the tool can currently do.
